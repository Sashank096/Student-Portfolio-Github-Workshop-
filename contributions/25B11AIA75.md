## Three Git Commands I Learned
1. `git status` — shows the state of the working directory and staging area, including which files are changed or staged.
2. `git add <file>` — stages a specified file's changes so they can be included in the next commit.
3. `git commit -m "message"` — records the staged changes in the local repository as a commit with a descriptive message.

## Purpose of GitHub
GitHub hosts Git repositories online and provides tools for sharing projects and collaborating, such as reviewing code and coordinating contributions.

## One Benefit of Branches
Branches let developers work on a change independently without immediately changing the main branch, making it easier to review and integrate the work safely.
